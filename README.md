# GitHub Pages Portfolio Site

## Purpose
This folder is your public portfolio hub. Anyone can view it without signing up.

## Publish on GitHub Pages
1. Create a new GitHub repository (example: `portfolio-site`).
2. Upload `index.html` and `styles.css` from this folder.
3. In repository settings, open **Pages**.
4. Source: `Deploy from a branch`.
5. Branch: `main` and folder: `/ (root)`.
6. Save and wait for the published URL.

## Connect your demos
In `index.html`, replace these placeholders:
- `https://YOUR-STREAMLIT-OR-HF-DEMO-URL`
- `https://github.com/YOUR_USERNAME/YOUR_REPO`
- `https://github.com/YOUR_USERNAME`

## Add more projects
Copy the existing `<article class="project-card">...</article>` block and update title, summary, stack tags, and links.
